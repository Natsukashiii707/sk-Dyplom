Про систему ImageLens
Архітектура, технології та принципи роботи
🏗️ Архітектура
Browser → Flask REST API → PIL/Pillow → SQLite
                  ↓
     Leaflet.js (GPS Map)

Клієнт надсилає зображення через multipart/form-data на Flask-бекенд.

Бекенд вилучає метадані через PIL/Pillow ExifTags, обчислює AI-оцінку за евристичними сигналами та зберігає результат у SQLite.

GPS-координати відображаються через Leaflet.js + OpenStreetMap.

⚙️ Технічний стек
Фронтенд HTML5 CSS3 JS ES6
Бекенд Python 3 Flask
База данихSQLite 3
Метадані PIL/Pillow piexif
Карти Leaflet.js OSM
Шрифти Syne + Space Mono
🔍 Алгоритм детекції AI

Система використовує 5 евристичних сигналів з ваговими коефіцієнтами:

Відсутність EXIF (+25)
AI-зображення зазвичай не мають даних камери
AI-інструмент у Software (+40)
«Stable Diffusion», «Midjourney» у полі EXIF Software
XMP CreatorTool (+35)
Ідентифікатор AI-інструменту в XMP-метаданих
Стандартні AI-розміри (+12)
512×512, 1024×1024, 768×1344 та інші типові canvas
Відсутні поля камери (+18)
Немає дати, моделі та об'єктиву одночасно

💡 Висновки та рекомендації
📍 МЕТАДАНІ
  • ✅ PIL/Pillow — найкращий вибір для швидкого локального аналізу
  • ✅ ExifTool — максимальна повнота (500+ форматів, повна XMP/IPTC)
  • ⚠️ Google Cloud Vision — виправданий при потребі AI-збагачення
  • ❌ AWS Rekognition — не підтримує XMP/IPTC
📡 ДЕТЕКЦІЯ AI
  • ✅ Hive AI — найвища точність (92%), для виробничих систем
  • ✅ AI or Not — баланс точності та вартості
  • ⚠️ CNNDetection — безкоштовно, але потребує GPU
  • 💡 Метадата-евристика — для первинного фільтрування
